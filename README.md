# Try Solarpunk

Gear for recovering scrollers. An openly AI-made TikTok channel (@trysolarpunk) and a Fourthwall shop.

| Folder | What's in it |
|---|---|
| `brand/` | Logo, banner, TikTok avatar, brand sheet |
| `store-photos/` | Product listing photos (3:4) |
| `merch/` | Print-ready merch art (transparent PNG) |
| `products/` | Product renders. The STL and CAD files stay local (see `.gitignore`) |
| `pipeline/` | The video pipeline Claude runs: plans → songs (YuE2) → clips (LTX-2.5) → edits, one GPU session per batch. See `pipeline/README.md` |
| `site/` | The waitlist site (Cloudflare Pages + D1). See `CLAUDE.md` |
